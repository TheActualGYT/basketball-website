# JBA - Custom Basketball League Website

Modern static site for the JBA custom basketball league.

- Dark gray-black theme with purple-to-pink accents matching the logo
- Sections for teams, players, standings, and news
- Responsive design
- Deployed via Vercel from this GitHub repo

## Logo
Replace `logo.png` with the official JBA logo PNG if needed.

## Deploy
Import this repo into Vercel for automatic deployments on push.
